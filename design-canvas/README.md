# Design canvas source

These two files are the source of the original interactive design boards for Deck One:

- `Main.dc.html`: top view with live switches for finish and spine
- `Profile.dc.html`: the three spines, side profile and specification

They were made in a design-canvas tool and use its component runtime (`support.js`), so they **won't render on their own** if opened directly in a browser. They're kept here as the design record. For drawings you can open, print or build from, use the SVGs in [`../drawings`](../drawings).
