# Design canvas source

These files are the source of the original interactive design boards for Deck One:

- `Main.dc.html`: keyboard top view, with live switches for finish, palm-rest type and palm-rest material
- `Modules.dc.html`: underside bays, the three palm rests, materials, and the big-and-sweaty-hands features
- `Spine.dc.html`: the separate Spine hub, inside and rear I/O

They were made in a design-canvas tool and use its component runtime (`support.js`), so they **won't render on their own** if opened directly in a browser. They're kept as the design record. For drawings you can open, print or build from, use the SVGs in [`../keyboard/drawings`](../keyboard/drawings) and [`../spine/drawings`](../spine/drawings).
