# Design canvas source

These files are the source of the original interactive design boards for Deck One:

- `Main.dc.html`: top view, with live switches for finish, palm-rest type and palm-rest material
- `Modules.dc.html`: the 5 mm slab, the three palm rests, materials, and the big-and-sweaty-hands features

They were made in a design-canvas tool and use its component runtime (`support.js`), so they **won't render on their own** if opened directly in a browser. They're kept as the design record. For drawings you can open, print or build from, use the SVGs in [`../drawings`](../drawings).
